# 喵呜动漫 🌸 · 多渠道动漫搜索播放网页

纯前端（HTML + CSS + 原生 JS）+ 本地代理，无需构建。

## 启动（必须用这种方式，不要直接双击 index.html）

```
python serve.py
```

然后浏览器打开 http://127.0.0.1:8081

> 为什么必须用 serve.py：浏览器有 CORS 跨域限制，页面 JS 直连外部资源接口和 m3u8 会被拦截
> （表现为"所有渠道都播不了"）。serve.py 自带 `/proxy?url=` 本地代理：
> - 搜索/详情/探测请求经它转发，绕开跨域；
> - m3u8 播放清单由它在服务端把内部分片地址重写为再走代理，hls.js 零配置即可播放；
> - 代理强制直连，不受系统代理（Clash 等）环境影响。
> 直接双击 index.html 时页面会提示降级为直连模式，大部分渠道不可用。

## 功能

- 🔍 搜索动漫：多渠道并行搜索、按标题智能合并同一部番，支持模糊匹配
- 📺 8 个实测渠道：暴风 / 360 / 360备用 / 最大 / 红牛 / JRS / 速播 / uku（2026-10-26 全部实测搜索→详情→m3u8 首集探测通过）
- ✅ 播放前三关检测：详情有数据 → 剧集非空 → 视频地址实测可达（m3u8 内容校验），任何一关不过自动换下一个渠道
- 🎬 hls.js 内嵌播放，支持选集 / 上下一集 / 全屏；换集时也会先探测该集
- 📌 播放历史（localStorage），点一下续看
- 🐱 可爱卡通风：Q版猫娘看板娘、粉嫩渐变、果冻按钮、漂浮装饰

## 新增 / 更换渠道

编辑 `app.js` 顶部的 `CHANNELS` 数组：

```js
{ key: 'xxx', name: '显示名', api: 'https://xxx/api.php/provide/vod' }
```

渠道接口为苹果CMS(CMS10) 标准 vod 接口。换渠道前可先跑自测验证：

```
node _selftest.js 火影忍者
```

自测脚本与页面逻辑同源（同样走本地代理），能跑出 `m3u8可播✅` 的渠道才值得加进去。
渠道挂了不用改代码——检测层会自动把它标记为不可用并跳过。

## 说明

- 所有内容来自公开网络资源接口聚合，仅供学习交流，请支持正版。
- 渠道延迟方差大（0.9s~60s+），单渠道偶发超时正常，多渠道+自动换源会兜底。
- 检测逻辑在 `app.js` 的 `probeVideoUrl()` / `detectChannel()`；检测结果在本页会话内缓存。
